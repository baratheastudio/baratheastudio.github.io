Product setup

The theme reads ordinary Shopify product data. Set it up as below and the cards, product pages, size guide and Client care all fill themselves in.

Options

Use one option for color and one for size, in either order, or a size option alone. The theme finds the color option as the first option with Shopify swatches or, failing that, the first whose name reads as a color (Color, Colour, Couleur, Farbe, Colore, Kleur). It finds a size option by its name: one of the Size option names (see Sizes and the size system). Other options work too, such as Material or a gift card's amount. They show as buttons and start on the first choice in stock, so Add to bag is ready at once.

  • An option with a single value is printed as a line above the sizes ("Color: Camel"), not as a choice. You can turn this off in the Colors and sizes block.
  • Combined listings work: each color can be its own product, and choosing a color moves to that product.
  • Quick add on cards handles one size option of up to 8 sizes, with or without a color, and adds a product with only a color as shown. Longer size runs, products with more than 2 options, products with an option that is neither a size nor a color (Material, a gift card's amount) and products with two options of which neither is a color open a quick view sheet. So does a product with a minimum quantity above 1; see Quantity rules and volume pricing.

Sizes and the size system

  • Size option names (Theme settings > Product page) lists the option names that count as a size, separated by commas, in any case. Only a size waits for the shopper's choice before Add to bag and express checkout (Size before buy). The default covers Size, Taille, Talla, Taglia, Groesse, Größe, Ring size and EU size, US size, UK size, FR size, IT size. If your size option has another name, such as Shoe size or Waist, add it to the list; write it as it is spelled on your products. Gift cards never wait for a size.
  • Size system label (Theme settings > Product page) names your sizing, for example FR, IT, EU or US. The size label then reads "Size (FR)". Leave it empty when your sizes name their own system, such as "FR 38". The Colors and sizes block can override it per template, for example mm for rings.
  • Sold out means no stock with tracking on and Continue selling when out of stock off. Sold-out sizes stay visible and lead to Ask about this size.
  • Low stock is off by default. If you turn it on, it shows only for tracked inventory, at or below the number you set. There are no countdowns.

Size guide

The Size guide link beside the size label opens your guide in a drawer. A product finds its guide in this order, and the first match wins:

  1. The page picked in the product template's Size guide block. The setting accepts a page reference metafield, so each product can name its own guide.
  2. The Product type rules in Theme settings > Product page: one rule per line, a product type, a colon, then a page handle with an optional tab. * matches every type; a rule for the product's own type wins over it wherever it sits in the list. Capital letters do not matter.
  3. The Default size guide page, then the Client care size guide page.
Coats: size-guide#women
Shoes: size-guide#shoes
Jewelry: size-guide#rings
*: size-guide#women

Build the guide on a page with the size-guide template: one Tab block per tab (Women, Men, Shoes, Rings), each followed by its How to measure and Table blocks. A tab named "Women" opens with ?tab=women; the drawer opens the tab from the rule. Tables marked "Measurements in cm" get a cm and inch switch.

The size-guide template's Shoes tab has Women's shoes (EU 35 to 41) and Men's shoes (EU 40 to 46) tables, and its Rings tab eleven sizes, US 4 to 9. They convert exactly as the drawer's built-in tables, so a shoe or a ring converts the same way on the page and in the drawer. If you change a table, change it for your own sizing.

Without any page, the drawer can show a built-in conversion table (Women's clothing, Men's tailoring, Shoes or Rings), chosen in the block or in Conversion table when there is no page.

Swatches

Swatches are Shopify's own. In the product, link the color option to a color metafield or give each value a color or an image swatch, and the cards and product page show them. Without swatch data, cards show a count ("3 colors") and the product page shows text buttons. Product cards show up to the number set in Swatches shown before +N; choosing one swaps the card's picture.

The same swatches work as color filters, once Color is added in Search and Discovery.

Pictures per color

With Show only the chosen color's pictures on (in the Product information section, on by default), the gallery shows the pictures of the chosen color only. Order the product's media like this:

  1. Pictures for every color first, for example a fabric close-up. They show with every color.
  2. Then each color's pictures together, starting with the picture set as that color's variant picture.

A color's pictures run from its variant picture to the next variant picture. Give each color at least two pictures. Use the same shape across the store, at least 1600 px on the long side: for the preset, square on pure white (#FFFFFF); portrait 4:5 if you set the cards and galleries to portrait.

Metafields

Two are Shopify's standard definitions: turn them on in Settings > Custom data > Products. The two custom ones are yours to create, with exactly these namespace, key and type.

Product metafields the theme reads

descriptors.subtitle
Product subtitle (standard)		Single line textThe material line under the name on product pages and cards, and in Product spotlight. Example: "Double-faced wool, horn buttons".
descriptors.care_guide

custom.fit_line
Fit line (create it)		Single line textThe Fit line block. Connect it once per product template: select the block, then use the dynamic source button beside Text. Example: "Cut close to the body. The model is 178 cm and wears FR 36."

Dimensions (create it)		Multi-line textThe Specifications block on the bag template reads it by itself: one row per line, a label, a colon and a value, for example "Width: 30 cm". Nothing to connect.

Any text setting with a dynamic source button can read another metafield of yours; the Specifications block can name any metafield as namespace.key.

Product templates

Pick a template for each product under Theme template in the product's admin page.

product (default)
Shoes and clothing. Sizes with the Size guide link beside the label, Fit line, the quantity field, Promises and help, and three panels: Details, Care, Shipping and returns.
product.bag
Bags and small leather goods. No size guide; Personalization (initials, up to 3 characters); a Dimensions table from custom.dimensions, open by default.
product.jewelry
Rings and cuffs. Sizes labeled mm, a Size guide link (with no guide page found, it shows the built-in ring table), and Personalization (up to 12 characters).
product.jewelry-plain
Earrings and chains. The jewelry page without Personalization and without the Size guide link.

In the preset, every product template has a square gallery that shows the whole picture, the designer above the name and the quantity field. Each template keeps its own block order and settings. To make another, open the editor's template menu and choose Create template, based on the closest one.

Tags

badge: tags
badge:New, badge:Limited edition, badge:Made to order: the text after the colon shows on the card as written. Sold out and Sale are automatic; up to two badges show.
final-sale
Marks the product as final sale (the tag is set in Theme settings > Shipping and returns). See Final sale.
Hide compare-at
A tag you name in Theme settings > Prices, for example no-compare, hides the compare-at price of that product.

Quantity rules and volume pricing

With Shopify's B2B features, a catalog can give each variant quantity rules (a minimum, a maximum and an increment) and volume pricing (a lower price from a quantity). You set them on the catalog in your admin (Products > Catalogs). A signed-in B2B customer sees them; nothing changes for anyone else.

  • Product page. The quantity field starts at the minimum and steps by the increment, up to the maximum (and the stock, when you track it). A rule that is not the default is listed under the field: "Minimum of 2 / Increments of 2 / Maximum of 10". Price breaks show as a small Volume pricing table, with the row for the chosen quantity, plus what is in the bag, marked. A typed quantity off the rule moves to an allowed one, and a line says which rule moved it.
  • Already in the bag. When the bag holds the minimum, the field starts at one increment, the most it allows is what the rule still leaves, and the label reads "Quantity (4 in your bag)".
  • Show quantity off. The Buy buttons block shows the quantity field by default, in every template. With Show quantity turned off, Add to bag still adds the minimum, and express checkout uses it too.
  • Quick add. A product with a minimum above 1 on any variant opens quick view instead of adding at once, so the shopper sees the rule; quick view adds each size's own minimum.
  • Bag. Each line follows the same rule: minus stops at the minimum (Remove takes the line out), plus stops at the last whole increment under the maximum, the buttons step by the increment ("2 fewer"), and a typed quantity off the rule is refused with a short line. The rule shows under the line.

The theme adds no rules of its own. Without them, the quantity field, quick add and the bag work as for any product.

Style codes, personalization, gift cards

  • Style code. The SKU of the chosen variant, shown in the Details panel as "Style FC-0112" and sent with Client care messages. Style code label in Theme settings > Product page changes the word.
  • Personalization. The block saves the shopper's text and style as line item properties on the order. Write how long it takes and whether it can be returned in its Policy text. To make personalized items final sale, turn on Personalized items are final sale.
  • Complementary products for Complete the look are set per product in Shopify's Search and Discovery app.
  • Gift cards. A gift card's amounts (Shopify's Denominations option) start on the first amount, and Add to bag is ready at once: a gift card never waits for a size. On cards, quick add opens quick view to choose the amount. A gift card product shows the recipient form (name, email, message and send date) when the Buy buttons block's Show the gift card recipient form is on. The gift card page shows the picture set in Theme settings > Bag > Gift card picture.
  • Descriptions. The Story block shows the first lines of the description with Read more. Start with a sentence or two about the product, then the details.
