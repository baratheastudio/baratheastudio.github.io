Translations and right-to-left

Version 1.0.0 ships in English. Every word the theme shows can be translated, and the layout mirrors for right-to-left languages.

Status in 1.0.0

Translating the theme

  • One language, your own wording: Online Store > Themes > ... > Edit default theme content. Search for a word and change it; your text replaces the theme's in the store.
  • More than one language: add languages in Settings > Languages, then translate with Shopify's free Translate and Adapt app. The footer and the phone menu show a language selector once a second language is published.
  • Your own content (products, collections, pages, menus and the text you type into sections) is translated in the same app.

Some lines follow the shopper's language by themselves when their setting is left empty, for example the promises in the bag and the final sale line. Text you type into a setting is shown as you typed it.

Right-to-left languages

For Arabic, Hebrew, Persian, Urdu and the other right-to-left languages Shopify supports, the theme sets the page direction to right-to-left. Layouts use start and end rather than left and right, so they mirror without extra settings:

  • pictures on the "start" side move to the right, and drawers open from the other side;
  • arrows and chevrons point the other way;
  • labels drop capitals and letter spacing, which do not suit those scripts (Capital letters for labels and buttons is never applied in right-to-left languages).

If the fonts you pick have no Arabic or Hebrew letters, browsers use the device's own font for those letters. If anything reads wrong in a right-to-left language, please tell us: see Support.
