Theme settings

Settings that apply across the whole store. Open them in the theme editor under Theme settings. Defaults below are the theme's own; the Barathea preset sets its look values on top (see The preset).

Without a logo, the header prints the store name in the text font.

Colors

The preset sets four schemes; their values are on The preset. If you change colors, keep text at 4.5:1 against its ground.

Colors settings
SettingChoices and defaultNotes
Scheme 1 is the page ground, scheme 2 a quiet ground, scheme 3 the night ground (pictures stay light on it) and scheme 4 a season ground. Sections pick a scheme in their own settings; text over pictures uses the scheme chosen below.
Color schemesColor schemesSet by the presetEach scheme sets: Background, Background gradient, Text, Quiet text, Hairline, Field and control lines, Image ground, Buy button, Buy button label, Service links.
Text over picturesColor schemeDefault: Scheme 3The scheme for credits and headings printed over a picture (Hero, Image banner, Shop the look full screen). Pick a dark scheme when the pictures are light at the bottom. The shade below takes its background color.
Shade behind text over imagesSlider, 0 to 80%, in steps of 5Default: 40%How dark the soft shade gets where text sits over a picture. 0% turns it off.

Typography

Each page loads at most four font files: the interface font in two weights and the text font in regular and italic.

Typography settings
SettingChoices and defaultNotes
Two fonts carry the whole store: one for the interface and one for text. Choose fonts from the Shopify font library.
Interface fontFontDefault: Instrument SansLabels, menu, buttons, prices and badges. A medium weight reads best at small sizes.
Text fontFontDefault: NewsreaderProduct names, headings, body text, credits and service links.
Heading sizeSmall / Medium / LargeDefault: Medium
Capital letters for labels and buttonsOn or offDefault: OnNever applied in right-to-left languages.

Button and field heightSlider, 44 to 56 px, in steps of 2Default: 48 px

Product page

See Sizes and the size system and Size guide.

Product page settings
SettingChoices and defaultNotes
Sizes, buying and the size guide on every product page. Gallery shape and layout are set per template in the Product information section.
Sizes
Size option namesTextDefault: Size, Taille, Talla, Taglia, Groesse, Größe, Ring size, EU size, US size, UK size, FR size, IT sizeShoppers choose a size before Add to bag and express checkout only on options with one of these names, in any case. Separate names with commas. Other options, such as Color, Material or Amount, start on the first available choice. Gift cards never ask for a size.
Size system labelTextShown beside the size label, for example FR, IT, EU or US. Leave it empty when your sizes name their own system.
Select a size for the shopperWhen only one size is in stock / NeverDefault: When only one size is in stock
Show Low stock on sizesOn or offDefault: OffOnly for sizes whose inventory Shopify tracks. Off by default: no countdowns, no pressure.
Low stock at or belowSlider, 1 to 10Default: 2
Buying
Wait for a size before express checkoutOn or offDefault: OnAccelerated checkout buttons stay inactive, with a short note, until the shopper chooses a size, so nobody buys a size they did not pick. The buttons keep their own colors.
Show the buy bar on phonesOn or offDefault: OnAppears when Add to bag scrolls out of view. It never adds a size nobody chose.
Style code labelTextShown before the SKU in the Details panel, for example Style FC-0112. Leave empty for the theme's word, Style, in the shopper's language.
Size guide
How a product finds its size guide: the page picked on its Size guide block first, then the rules below, then the default page.
Default size guide pagePageWithout it, the Client care size guide page is used.
Product type rulesTextOne rule per line: a product type, a colon, then a page handle with an optional tab. Example: Coats: size-guide#women. Use * for every type.
Conversion table when there is no pageNone / Women's clothing / Men's tailoring / Shoes / RingsDefault: NoneShown in the size guide drawer only when no page is found.

Shipping and returns settings
SettingChoices and defaultNotes
One place for delivery times, returns windows, duties and final sale. The bag, the product page and the Shipping and returns section read these settings, so they always agree. Never type prices or currencies here.
Up to three groups of countries, each with its own delivery time, returns window and duties. Shoppers in other countries see the "Every other country" row. A part left empty is not shown.
