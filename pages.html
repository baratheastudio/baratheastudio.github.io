Set up your store

Pages

Barathea comes with a template for each page a fashion house usually needs. Each is a set of sections you can change, reorder or remove.

Making a page

  1. In Online Store > Pages, add a page, write its title and any text, and pick its template under Theme template.
  2. Open it in the theme editor (choose the template from the menu at the top) and fill its sections.
  3. Link it from a menu, and from Theme settings > Client care where it is a Client care page.

The page's own text shows in the Page section, which every template has (first, except on Workroom, where it follows the Hero); turn off Show the page content to show only the sections, or Hide the title to keep it for screen readers and search only. Template sections hold sample text until you change it.

Client care pages

Three pages power Client care, so set them first:

Contact
Template page.contact. Write to us and Arrange a visit open it with the topic chosen and the shopper's product, color and size filled in. Its topics are blocks: rename, reorder or add them. The Topic code is what a link uses (?topic=visit).
Boutiques
Template page.boutiques. One Boutique block per shop: picture, name, city, address, hours for each day (today is marked, in the shop's time zone if you give one), phone, email, services, a visit link and a map link. A city filter appears with more than three boutiques in two cities or more.
Size guide
Template page.size-guide. Tabs (Women, Men, Shoes, Rings), How to measure and size tables. See Size guide.

An Arrange a visit page

Create a page named "Arrange a visit" with the page.contact template. In its Contact form, move the Arrange a visit topic to the top and write a line about visits in the form's text. Link to it as /pages/arrange-a-visit?topic=visit. If you would rather keep it apart from Contact, make a template for it in the editor (Create template, based on contact). See Arrange a visit.

Policies

Write your refund, shipping, privacy and terms policies in Settings > Policies. The theme links to them from promises, the final sale line, product panels, the FAQ and the Shipping and returns section, so the words live in one place.

More sections for pages

Any page can also take Address and hours, Team, Timeline, Letter, Quote, Logo wall, Collapsible content, Service list, Price table, Video and the picture sections. See Sections and blocks.
