Support

Write to us and a person replies within one business day.

Write to us

Email support

Reply time
Within one business day. Business days are Monday to Friday, Gulf Standard Time (UTC+4), not counting public holidays in the United Arab Emirates.
Who replies
A person who knows the theme. Fixes to the theme itself reach you in a theme update.
Language
English.

What to include

  • Your store address, for example your-store.myshopify.com.
  • The theme version, shown under the theme name in Online Store > Themes.
  • The page where you see the problem, what you expected and what happened instead.
  • Screenshots or a short screen recording.

Never send a password

If we need to look inside your admin, we will ask you for a collaborator request code.

What support covers

  • Installing and setting up the theme.
  • Any setting, section, block or template in these docs.
  • Bugs in the theme's own code: layouts that break, links that lead nowhere, features that do not work as written here. Critical bugs are fixed first and released in a theme update.
  • Changes Shopify asks every theme to make.

What support does not cover

  • Custom code: code you or someone else added to the theme, Custom Liquid sections and blocks, and edited theme files.
  • Apps, their blocks and embeds. Please ask the app's developer; we will tell you if something looks like a theme problem.
  • Design work, writing and entering content, photography, and store setup outside the theme (domains, email, payments, shipping rates).
  • Moving custom code to a new version of the theme.

For work like this, a Shopify Partner can help; see the Shopify Partner Directory.

Before you edit code

  • Duplicate the theme first (Online Store > Themes > ... > Duplicate) and work on the copy.
  • Code edits are not covered by support and are not carried into theme updates. Keep a note of what you changed.
